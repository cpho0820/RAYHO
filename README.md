# 一人操作多機台標準工時計算器

本專案是「標準工時量測與應用」課程用的單檔網頁計算器，整合兩種人機同時作業情境：

- 一人操作 N 台相同機台
- 一人操作 N 台不同機台，不同機台模式 N 可選 2 到 4 台

## 教學用途

標準工時不只是傳統的平均時間、評比與寬放率計算，而是報價、產能規劃、生產排程、績效管理與現場改善的重要依據。本計算器用來協助學生理解一人多機情境下，操作員與機台之間的瓶頸關係。

## 計算邏輯

相同機台模式：

```text
操作員時間 = N × (L + UL + P)
機台時間 = L + UL + M
CT = MAX(操作員時間, 機台時間)
ST = CT / N × K + ALL
```

不同機台模式：

```text
操作員時間 = Σ(Li + ULi + Pi)
各機台時間 = Li + ULi + Mi
CT = MAX(操作員時間, 各機台時間最大值)
ST = CT × K + ALL
```

直接開啟 `index.html` 即可使用。
